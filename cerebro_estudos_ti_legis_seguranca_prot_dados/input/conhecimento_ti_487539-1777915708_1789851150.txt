=== SECAO [TI_SEC_001]: Conceito de Dado Anonimizado (Artigo 12 da LGPD) ===
Esta seção apresenta o conceito legal de dado anonimizad o segundo a LGPD. O dado anonimizad o não é considerado dado pessoal para fins da LGPD, desde que o processo de anonimização não possa ser revertido de forma razoável. Se a reversibilidade for possível com meios razoáveis, o dado continua sendo pessoal. A 'Regra de Ouro' orienta que, se for possível reidentificar, o dado ainda é pessoal.

-- Conceitos-chave --
Termo: Dado Pessoal | Tipo: Padrão | Definicao: Informação relacionada a uma pessoa natural identificável.
  Vantagens de Dado Pessoal: Identificação direta de indivíduos; Fundamental para operações legais
  Desvantagens de Dado Pessoal: Risco de privacidade; Conformidade exige controles
  Casos de uso de Dado Pessoal: Registros de pacientes; Análises com dados identificáveis
Termo: Dado Anonimizado | Tipo: Padrão | Definicao: Dado que não pode identificar o titular por meios razoáveis.
  Vantagens de Dado Anonimizado: Reduz risco de identificação; Facilita compartilhamento para pesquisa
  Desvantagens de Dado Anonimizado: Pode ser revertido com esforço razoável
  Casos de uso de Dado Anonimizado: Pesquisa em saúde pública; Compartilhamento de dados para estudos
Termo: Dado Pseudonimizado | Tipo: Padrão | Definicao: Dado que não identifica diretamente, mas pode ser reidentificado com chaves adicionais.
  Vantagens de Dado Pseudonimizado: Reduz identificação direta; Mantém capacidade de reidentificação sob controle
  Desvantagens de Dado Pseudonimizado: Ainda é dado pessoal; Chaves devem ser protegidas
  Casos de uso de Dado Pseudonimizado: Pesquisas com controle de chaves
Termo: Processo de Anonimização | Tipo: Processo | Definicao: Conjunto de técnicas para tornar dados não identificáveis de forma estável.
  Vantagens de Processo de Anonimização: Possibilita compartilhamento seguro
  Desvantagens de Processo de Anonimização: Pode ser reversível se não adequado
  Casos de uso de Processo de Anonimização: Anonimização de bases de dados para pesquisa
Termo: Esforço Razoável | Tipo: Padrão | Definicao: Conjunto de fatores (custo, tempo e tecnologia) que influenciam a reversibilidade.
  Vantagens de Esforço Razoável: Ajuda a determinar se reversão é viável
  Desvantagens de Esforço Razoável: Subjetivo e context-dependent
  Casos de uso de Esforço Razoável: Avaliação de risco de reidentificação

=== SECAO [TI_SEC_003]: Artigo 12: Perfis Comportamentais e Padrões da ANPD ===
Esta seção aborda o Artigo 12, que trata de perfis comportamentais e padrões da ANPD. O conteúdo descreve que dados aparentemente anonimos podem se tornar dados pessoais se puderem ser utilizados para identificar uma pessoa. A ANPD define padrões de anonimização e supervisiona a segurança de dados, com o objetivo de regulamentar o tratamento de dados para fins de pesquisa.

-- Conceitos-chave --
Termo: Perfil Comportamental | Tipo: Padrão | Definicao: Conjunto de dados que facilita a construção de um perfil da pessoa natural.
  Vantagens de Perfil Comportamental: Melhora a compreensão de padrões de comportamento
  Desvantagens de Perfil Comportamental: Risco de violação de privacidade
  Casos de uso de Perfil Comportamental: Monitoramento de comportamentos para políticas públicas
Termo: ANPD | Tipo: Padrão | Definicao: Autoridade Nacional de Proteção de Dados
  Vantagens de ANPD: Regulamentação e fiscalização de dados
  Desvantagens de ANPD: Pode criar burocracia
  Casos de uso de ANPD: Políticas de proteção de dados
Termo: Padrões de Anonimização | Tipo: Padrão | Definicao: Conjunto de técnicas padronizadas para anonimizacao de dados.
  Vantagens de Padrões de Anonimização: Padroniza o nível de anonimização
  Desvantagens de Padrões de Anonimização: Pode ser superado por técnicas novas
  Casos de uso de Padrões de Anonimização: Analises comparativas entre bases

=== SECAO [TI_SEC_004]: Artigo 13: Pesquisas em Saúde Pública ===
Artigo 13 autoriza o acesso de órgãos de pesquisa a bases de dados pessoais para estudo, desde que o tratamento ocorra dentro do órgão, em ambiente controlado, seguro, e com anonimização ou pseudonimização quando possível, obedecendo padrões éticos.

-- Conceitos-chave --
Termo: Artigo 13: Pesquisa em Saúde Pública | Tipo: Padrão | Definicao: Regula o acesso de bases de dados pessoais para estudos, com tratamento interno e controles de segurança.
  Vantagens de Artigo 13: Pesquisa em Saúde Pública: Protege informações sensíveis; Promove pesquisa em saúde pública
  Desvantagens de Artigo 13: Pesquisa em Saúde Pública: Pode restringir acesso externo; Complexidade de compliance
  Casos de uso de Artigo 13: Pesquisa em Saúde Pública: Estudos epidemiológicos; Pesquisas clínicas

-- Figuras e diagramas --
Figura 'Artigo 13: Pesquisa em Saúde Pública' (Texto/Diagrama): Autorização de acesso com ambiente controlado e anonimização/pseudonimização onde possível.
  Relacionado a: dado_pessoal, instituicao_pesquisa

=== SECAO [TI_SEC_005]: Comentários: Regras para Pesquisas em Saúde ===
Sessão apresenta as regras que regem o acesso e o repasse de dados em pesquisas de saúde: exigência de finalidade estrita, tratamento dentro da instituição, ambiente seguro, anonimização/pseudonimização sempre que possível, e padrões éticos. Observa ainda que repasse de dados pode ter regras específicas.

-- Conceitos-chave --

  Vantagens de Requisitos Obrigatórios para Acesso a Dados: Garante privacidade no estudo
  Desvantagens de Requisitos Obrigatórios para Acesso a Dados: Pode limitar a pesquisa
  Casos de uso de Requisitos Obrigatórios para Acesso a Dados: Pesquisas epidemiológicas
Termo: Dados Pessoais | Tipo: Padrão | Definicao: Dados que identificam ou podem identificar uma pessoa.
  Vantagens de Dados Pessoais: Potencial de insights; Desvantagens: Privacidade sensível
  Desvantagens de Dados Pessoais: Privacidade sensível
  Casos de uso de Dados Pessoais: Pesquisas com dados sensíveis
Termo: Ambiente Controlado e Seguro | Tipo: Padrão | Definicao: Espaço com controles de segurança e acesso restrito.
  Vantagens de Ambiente Controlado e Seguro: Reduz risco de vazamento
  Desvantagens de Ambiente Controlado e Seguro: Custos
  Casos de uso de Ambiente Controlado e Seguro: Laboratórios de dados

=== SECAO [TI_SEC_008]: Artigo 13: Regulamentação e Pseudonimização ===

Termo: Regulamentação e Pseudonimização | Tipo: Padrão | Definicao: Regulação pelo órgão competente; pseudonimização mantém dados como dados pessoais com proteções específicas.
  Vantagens de Regulamentação e Pseudonimização: Garante proteção adicional
  Desvantagens de Regulamentação e Pseudonimização: Complexidade de implementação
  Casos de uso de Regulamentação e Pseudonimização: Compliance de pesquisa

  Vantagens de Dado Pseudonimizado: Reduz identificação direta
  Desvantagens de Dado Pseudonimizado: Ainda é dado pessoal
  Casos de uso de Dado Pseudonimizado: Utilizado em pesquisas com controles de chaves
