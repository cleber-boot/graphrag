=== SECAO [TI_SEC_001]: Introdução à LGPD e Dados Pessoais ===
A LGPD estabelece regras para o tratamento de dados pessoais, com salvaguardas para dados sensíveis, direitos dos titulares e obrigações dos agentes de tratamento. O material introduz o conceito de dados pessoais, dados sensíveis e a necessidade de consentimento, bem como o papel de bases legais para o processamento.

-- Conceitos-chave --
Termo: LGPD | Tipo: Padrão | Definicao: Lei Geral de Proteção de Dados Pessoais (Lei n° 13.709/2018) que regula o tratamento de dados pessoais no Brasil.
  Vantagens de LGPD: Proteção de dados pessoais; Conformidade regulatória; Confiança do titular
  Desvantagens de LGPD: Custos de conformidade; Complexidade regulatória
  Casos de uso de LGPD: Contratos que envolvam dados pessoais; Processamento de dados de funcionários
Termo: Dados Pessoais Sensíveis | Tipo: Categoria | Definicao: Dados que revelam saúde, origem étnica, religião, convicções, vida sexual, entre outros, com proteção reforçada.
  Vantagens de Dados Pessoais Sensíveis: Proteção reforçada para informações sensíveis
  Desvantagens de Dados Pessoais Sensíveis: Requisitos legais mais rigorosos
  Casos de uso de Dados Pessoais Sensíveis: Seleção de riscos em planos de saúde; Estudos de saúde
Termo: Consentimento | Tipo: Processo | Definicao: Autorização explícita do titular para o tratamento de dados, com necessidade de ser específico e destacado para finalidades determinadas.
  Vantagens de Consentimento: Base legal clara; Transparência para o titular
  Desvantagens de Consentimento: Gestão de provas de consentimento
  Casos de uso de Consentimento: Tratamentos que envolvem dados sensíveis; Pesquisa com dados consentidos
Termo: Operadoras de planos privados de assistência à saúde | Tipo: Processo | Definicao: Entidades que fornecem planos de saúde e coletam dados de beneficiários para fins contratuais e operacionais.
  Vantagens de Operadoras de planos privados de assistência à saúde: Gestão de risco e cuidado médico
  Desvantagens de Operadoras de planos privados de assistência à saúde: Exigência de maior governança de dados
  Casos de uso de Operadoras de planos privados de assistência à saúde: Avaliação de elegibilidade; Gestão de sinistros e prontuários

=== SECAO [TI_SEC_002]: Dados Pessoais Sensíveis e Consentimento ===
A LGPD reconhece salvaguardas especiais para dados sensíveis. O tratamento de dados sensíveis costuma exigir consentimento específico, destacado, para fins específicos. Em determinadas situações, o tratamento sem consentimento pode ocorrer, como para pesquisas com anonimização ou para proteção da vida.

-- Conceitos-chave --
Termo: Dados Pessoais Sensíveis | Tipo: Categoria | Definicao: Dados que revelam saúde, origem étnica, religião, convicções, etc.
  Vantagens de Dados Pessoais Sensíveis: Proteção reforçada
  Desvantagens de Dados Pessoais Sensíveis: Processos de tratamento mais exigentes
  Casos de uso de Dados Pessoais Sensíveis: Avaliação de risco em saúde; Pesquisas clínicas
Termo: Consentimento Específico | Tipo: Processo | Definicao: Consentimento fornecido para finalidades específicas, com destaque para cada finalidade.
  Vantagens de Consentimento Específico: Clareza de finalidade
  Desvantagens de Consentimento Específico: Provedores devem manter registro do consentimento
  Casos de uso de Consentimento Específico: Processamento de dados sensíveis para finalidade definida
Termo: Anonimização | Tipo: Técnico | Definicao: Processo de tornar dados não identificáveis para reduzir riscos.
  Vantagens de Anonimização: Redução de risco de identificação
  Desvantagens de Anonimização: Pode reduzir utilidade dos dados
  Casos de uso de Anonimização: Pesquisas com dados anonimizados

=== SECAO [TI_SEC_003]: Hipóteses sem Consentimento (I, II, III) ===
A LGPD permite o tratamento de dados sensíveis sem consentimento apenas em hipóteses específicas: I) consentimento específico; II) estudos por órgão de pesquisa com anonimização; III) proteção da vida ou da incolumidade física do titular ou de terceiros.

-- Conceitos-chave --
Termo: Hipóteses sem Consentimento (I) | Tipo: Regra | Definicao: Consentimento específico para finalidades definidas.
  Vantagens de Hipóteses sem Consentimento (I): Possibilita tratamento autorizado
  Desvantagens de Hipóteses sem Consentimento (I): Exigência de prova de consentimento específico
  Casos de uso de Hipóteses sem Consentimento (I): Consentimento expresso para finalidades definidas
Termo: Hipóteses sem Consentimento (II) | Tipo: Regra | Definicao: Indispensável para estudos por órgão de pesquisa com anonimização, sempre que possível.
  Vantagens de Hipóteses sem Consentimento (II): Facilita pesquisa científica
  Desvantagens de Hipóteses sem Consentimento (II): Risco de reidentificação se não houver anonimização adequada
  Casos de uso de Hipóteses sem Consentimento (II): Pesquisas com dados anonimizados
Termo: Hipóteses sem Consentimento (III) | Tipo: Regra | Definicao: Indispensável para proteção da vida ou da incolumidade física do titular ou de terceiros.
  Vantagens de Hipóteses sem Consentimento (III): Proteção de vida e integridade física
  Desvantagens de Hipóteses sem Consentimento (III): Gestão de riscos de abuso
  Casos de uso de Hipóteses sem Consentimento (III): Intervenção de emergência médica/segurança

=== SECAO [TI_SEC_004]: Aplicações Práticas: Vida, Saúde e Fraude; Regras de Aplicação ===
A LGPD orienta aplicações práticas em cenários de vida, saúde e fraude, incluindo regras de aplicação e publicidade, portabilidade de dados e limitações ao compartilhamento de dados com finalidade econômica. Destaque para a proibição de determinadas práticas e para a obrigatoriedade de transparência.

-- Conceitos-chave --
Termo: Proteção da Vida (Alínea e) | Tipo: Alínea | Definicao: Contexto de risco iminente; prática de RH e saúde para proteção de vidas.
  Vantagens de Proteção da Vida (Alínea e): Proteção imediata de pessoas
  Desvantagens de Proteção da Vida (Alínea e): Procedimentos de avaliação rápida podem ser complexos
  Casos de uso de Proteção da Vida (Alínea e): Intervenção de emergência; Acesso rápido a dados para salvar vidas
Termo: Tutela da Saúde (Alínea f) | Tipo: Alínea | Definicao: Condições para acesso a dados de saúde para fins clínicos e administrativos.
  Vantagens de Tutela da Saúde (Alínea f): Melhora na qualidade do cuidado
  Desvantagens de Tutela da Saúde (Alínea f): Riscos de privacidade
  Casos de uso de Tutela da Saúde (Alínea f): Prontuários, gestão hospitalar
Termo: Prevenção à Fraude (Alínea g) | Tipo: Alínea | Definicao: Proteção de dados para evitar fraudes em serviços de saúde.
  Vantagens de Prevenção à Fraude (Alínea g): Redução de fraudes
  Desvantagens de Prevenção à Fraude (Alínea g): Impacto na experiência do usuário
  Casos de uso de Prevenção à Fraude (Alínea g): Detecção de fraude em planos de saúde
